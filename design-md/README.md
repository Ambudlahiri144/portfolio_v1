# DESIGN.md reference library

Vendored from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
(MIT). 73 brand design systems, one folder each.

A `DESIGN.md` describes how a project should *look* — tokens, type scale, spacing,
color, motion, component rules — the visual counterpart to `AGENTS.md`, which
describes how it should be *built*.

Nothing here is active. These are references to browse.

## Using one

Promote a brand to the project's design language by copying it to the repo root:

```
cp design-md/<brand>/DESIGN.md DESIGN.md
```

Agents read `DESIGN.md` from the root. Swap it to change direction; delete it to
go back to no prescribed system.
